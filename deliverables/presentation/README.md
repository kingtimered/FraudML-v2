依据本地 `DSC5001_Project instruction.docx`（位于5001-C61目录），课程强调有价值的问题、合适的统计机器学习方法、运行与验证、深入解释，以及有用的新结论。海报对应如下：

| 课程关注点 | 海报内容 |
|---|---|
| 有价值的问题与数据 | 相同审核容量下的欺诈排序；590,540笔有标签交易及时间跨度 |

## 修改与核验

从`FraudML-v2`目录运行：

```bash
python3 scripts/build_poster.py
python3 scripts/build_intro.py
node scripts/check_presentation.mjs
```

海报生成需要ReportLab及脚本中指定的Arial字体；其他操作系统可替换为许可允许嵌入的本地字体。HTML生成仅依赖Python标准库。浏览器核验需要Playwright和可用的Chrome/Chromium，可用`FRAUDML_PLAYWRIGHT_MODULE`指定包路径、`FRAUDML_CHROME_PATH`指定浏览器可执行文件。浏览器脚本会覆盖本次演示核验截图与记录，不运行训练。

核验记录在`results/presentation_qa_20261121/`：检查16组时期/预算、16组教学设置、2组每日对照、页面链接、320/390/1440像素宽度及深色显示。最终海报另经单页尺寸、文本、字体嵌入和渲染目视检查。`poster_manifest.json`和`intro_manifest.json`记录来源、生成代码与输出文件的SHA-256。
