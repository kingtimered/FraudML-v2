# 实验协议

版本：2026-11-21.plan2。参数以 `../configs/study_plan.json` 为准。本文件是事前列明的新比较协议，但原数据已用于旧研究，所有新增分析仍属回顾性。

## 数据与旧结果

训练交易表是唯一有监督评价数据。TransactionID 用于追踪，TransactionDT 用于排序和窗口，不作为原始模型输入；isFraud 不进入预处理、历史特征或队列规则。identity 暂不加入模型。

归档 split 由旧 JSON 精确时间边界定义：训练 413378 行，验证与测试各 88581 行。旧 AP 字段名 pr_auc，新结果使用 average_precision。归档值保存在 evidence/legacy_metrics，不能被新版训练覆盖。

历史标签可用性是实验假设：截止训练时已获得该训练部分标签。数据无真实标签到达时间，本版不模拟具体 7 天延迟。匿名上游字段的时点可用性不可完全验证；只保证本项目派生过程遵守时间边界。

## 时间窗口

相对日 d = floor(TransactionDT/86400)，与真实日历无关。开发区间左闭右开：

| 快照 | 训练日 | 评价日 | 评价长度 |
|---|---|---|---:|
| dev_F1 | [1,61) | [61,89) | 28 天 |
| dev_F2 | [1,89) | [89,117) | 28 天 |

两个评价期不重叠，后续训练可包含前期评价记录，符合扩展训练模拟但不是独立重复试验。训练量变化也会影响结果，不把变化仅归因为漂移。

第三个快照使用原完整训练部分，分别评分原验证期和原测试期。边界直接读取旧报告，不按日数近似重建。该快照不以验证期或测试期再调参；旧验证结果不作为新版未见验证证据。各期指标分别报告，不能合并不同模型快照的原始分数计算主 AP。

所有预处理、截尾、频率映射在对应训练部分拟合。历史特征可使用评价期内严格更早的未标记输入；同时间戳共享同一历史状态。当前交易分数不使用当笔或前笔的评价标签。

## 主要预算与排序

主要参考审核比例 r=0.005。每期全期预算 K=min(N,ceil(rN))；0.001、0.01、0.02 作为预算曲线，不在这些点之间选择最有利结论。参考比例是实验约定，不表示实际银行容量或经过优化的预算。

同一场景内所有模型使用相同交易集合与 K。新版同分按 TransactionDT、TransactionID 升序打破，旧复现保留旧排序。LR 主排序按 margin，LightGBM 按正类输出分数；另记录 LR 概率排序以解释旧结果。

主要精确率=命中/K，召回率=命中/该期全部欺诈数；K=0 时精确率记 NA，无正例时召回与 AP 记 NA。AP 为 average_precision_score 的阶梯加权定义。保存命中与分母，避免仅展示比率。

旧 Top-100/500 只在原验证/测试期作为归档口径补充，不能与其他时期相同比例的审核量混称相同容量。

## 每日场景

日批处理场景：每笔交易用当时信息评分，日末可见当天全部分数再挑选。只解释日内排序，不代表实时审批或跨日最优分配。

1. 每日比例：q_d=min(n_d,ceil(0.005*n_d))，无交易日 q_d=0。
2. 每日固定名额：B=8/16/32，q_d=min(B,n_d)，均为假设容量敏感性。
3. 与全期排序比较时，全期 K 必须重新设为 sum(q_d)。逐日取整会改变总容量，不能直接用全期 ceil(rN) 替代。本次审计确认原测试每日比例容量为458，全期比例容量为443；比较分配策略时两者都使用458。
4. 各方法每天按同一 q_d 选取，输出日命中、日容量、标签数。主汇总为 sum(h_d)/sum(q_d) 和 sum(h_d)/sum(F_d)。
5. 周级仅按评价期起始日每连续 7 个相对日汇总已有日队列，尾部不足 7 日注明；不能换成每周重新选名额。无欺诈日的日召回记 NA。

每日固定16笔只是在原测试31个日桶上形成496个名额，不等于旧500。一天精确率的最小步长为1/16=6.25个百分点，因此以期级和周级为主要展示尺度。少数小群体不再各自建立独立队列。

## 日期边界

审计比较每个分期内某日交易数与全表该日交易数，标记“因切分缺少部分交易”的日桶。例如原测试起点落在相对日152的中间，这是已知的切分截断。

首末交易没有落在午夜本身不能证明数据采集不完整。数据集覆盖边界是否有未观测交易无法核实，不直接称“首尾日均不完整”。主结果保留全部分期交易；仅对已知被切分的日桶另做排除敏感性，所有方法同步排除并重算容量及分母。该敏感性同时改变样本集合，不能将变化全归因为边界。

## 固定比较与结果解释

配置已列明，不再挑选测试赢家。主要增量对照为 LR2-LR0、LGB-H3减LGB-H0。LR1-LR0、LR2-LR1、H1-H0、H2-H1、H3-H2 为解释性对照。所有配置按相同时期、种子、输入契约报告，不以单一有利时期代替完整结果。

主要分析种子42，LightGBM线程2。模型随机性不在本版全面估计，是保留局限。旧版复现不强制替换线程，须保留旧运行设置以解释差异。

随机排序在全期容量K下期望命中为 K*F/N；每日容量下期望命中为 sum(q_d*F_d/n_d)，空日贡献0。这是给定标签组成的随机策略参照，不用标签来选择实际队列。保留seed42一次实际随机队列，不能把其表现视为随机策略均值。

## 区间与样本量约束

主要使用连续3日 moving-block配对bootstrap、1000次、seed20261121，每期单独计算。连续块不循环、不跨期，从所有合法起点均匀有放回抽取，拼接至原日桶数后截断。相同日期副本在所有模型中配对一致。固定模型和原历史特征，不在bootstrap重算训练或历史状态。

全期排序对抽中的固定分数重新取K=ceil(r*N_draw)，相同抽样所有模型容量一致；日队列汇总抽中各日的固定队列。若给出全期与每日策略差异，每个重采样中全期K须匹配抽中的日容量和。无正例重采样记NA并报告有效次数。

输出配对ΔHits、ΔPrecision、ΔRecall、ΔAP的2.5%和97.5%分位区间。对随机期望的比较在相同重采样标签组成下重算期望；期望基线不需要随机模型的训练。

日期相关、跨日重复代理实体、仅31个测试日桶和单个历史数据集均限制区间解释；固定3日块不保证消除所有依赖。该区间不包括训练样本变动和新环境的不确定性，也不是严格的多重检验校正。多个诊断区间一起展示，不以是否跨0筛选表格；区间包含0写证据不足，不能据此判等价。每100次审核多命中几笔是解释单位，不另设必须达到的改进门槛。
