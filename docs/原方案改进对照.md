# 相对原方案的改进点

本表以FraudML-main的course_proposal.md、final_report.md、现存代码与四份归档JSON为依据。原方案已经包含时间切分、训练期预处理、严格历史特征、固定审核预算、LR退化讨论和本地服务原型。新版的贡献是在这些基础上增加受控实验、修复正确性问题并补齐可复算证据，不将已有内容重复算作创新。暂不安排成员分工。

## 逐项对照

| 方面 | 原方案已有内容与不足 | 新版实际改进 | 证据与结论 |
|---|---|---|---|
| 研究主线 | 主要比较模型与金额排序在Top500中的命中，兼顾历史特征和LR退化 | 聚焦时间/预算稳定性、LR修复、历史增量三个可检验问题 | 完成七配置×三个训练快照，21次拟合；不要求新方法必须优于基线 |
| 时间评价 | 原70/15/15切分；额外比例窗口存在测试集嵌套 | 增加两个互不重叠的28天开发评价期；原验证/测试共享训练快照 | 分开解释模型快照变化与时期变化，不将四期当独立重复实验 |
| 审核预算 | Top100/500为全期固定名额，跨不同大小窗口含义会变化 | 主指标改为全期0.5%，完整保留0.1/1/2%及Top100/500 | 容量比例可比较；0.5%是实验参考，不能称业务最优 |
| 每日有限名额 | 原固定K针对整期；没有真实每日容量和审核成本 | 每日8/16/32及每日0.5%作为日末批处理补充，与全期匹配实际总名额 | 测试每日0.5%为458笔、全期0.5%为443笔；避免混入多审15笔的收益 |
| LR失效分析 | 原文已有极值、概率饱和和margin诊断讨论，部分扩展证据未完整恢复 | 固定LR0/1/2拆解截尾和正则化，保存逐笔概率/margin、收敛与贡献分解 | 测试主预算命中0→376→383；仅换margin未解决底层排序问题；强正则并非跨期稳定增加命中 |
| 历史特征消融 | 原有四个严格过去累计字段，缺失代理实体共组 | H1保留旧法；H2仅修缺失处理；H3再增加四个近期字段 | H3−H0命中差为+2/−11/+4/−7，不能宣称稳定获益 |
| 输入正确性 | 原代码只有整列浮点时规范整数编码，混合批次可能产生123与123.0差异 | 逐值规范化并拒绝无效编码；检验单笔、混合批次和保存加载 | 所有新版候选共用输入契约，避免批次改变编码 |
| 历史正确性 | 原代码已经严格使用过去时间，不用未来标签 | 保留原则，补充同时间戳、24小时边界、随机前缀及任意分块测试 | 不是首次实现严格历史；新增的是近期字段与更完整的边界核验 |
| 不确定性 | 原Markdown没有区间；Word记载bootstrap/CV等，但部分证据缺失 | 主分析给出每期1000次配对3日块区间；新增1/7日块敏感性 | 训练不确定性、日期/实体相关和多重比较仍有限制；不选择最有利块长 |
| 数据质量 | 原项目已有周欺诈率和数值极值漂移审计，缺少全列质量表 | 补齐394列三分区的缺失率、分位数、常量、非有限值、未知类别、重复组合及关键字段每日分布 | V323训练最大49、测试1411；跨期相同输入组合不能直接认定泄漏或误标 |
| 日期影响 | 原报告讨论分布变化，但缺少完整日窗影响清单 | 遍历全部连续1/2/7日省略窗，共332个；同时保留完整主结果 | 排除171/172日后LR0从0/443恢复275/414；每日策略的相对优势从+301变−8，解释边界更明确 |
| 随机基线 | 单个seed42随机结果有抽样波动 | 增加同容量随机命中的条件期望，保留单次示例 | 不把一次随机排序当稳定性能，也不声称有限样本AP期望等于欺诈率 |
| 复现证据 | 四个JSON与报告可读，但缺少部分模型/逐笔扩展证据及完整环境锁定 | 旧代码重跑3次；新版保存模型、逐笔分数、队列、参数、哈希、诊断与独立核验 | 六组当前环境共同基线逐笔对齐；旧归档小幅差异如实保留，不伪称全部精确复现 |
| 独立环境 | 旧运行没有完整跨环境验证 | 新建不继承系统包的环境，完成安装、pip check、10项测试及合成端到端核验 | 证明基本安装和流程可用；没有在新环境再做真实数据完整训练 |
| 作业交付 | 原Markdown与Word状态不同，部分扩展缺脚本或附录 | 新增正式中文报告、补充结果、可追溯图表及轻量提交包 | 旧扩展不继承为新版实测结果；提交包不含原始交易、逐笔分数或模型 |
| 工程范围 | 原项目已有HTTP/Java互操作原型，工程展示占用篇幅 | 新版聚焦离线实验、历史和队列一致性，原服务保留归档 | 将主要工作量放在研究证据；不将本地互操作等同生产部署 |

## 新增工作带来的判断变化

1. **“LR失败是概率饱和”需要收紧。** margin排序仍失败，训练期截尾才明显改善；原始字段分布、线性贡献和日期集中度共同提供解释，但不能锁定唯一原因。
2. **“增加历史特征能改善模型”没有获得稳定支持。** 主分析区间跨0；测试期7日块区间为负，不能只挑跨0结果，也不能把未显著当作等价。
3. **“每日限额更好”只在特定数据组成和模型上出现。** 容量匹配、日期省略和较好模型的负向对照表明，它不构成长期最优策略证据。
4. **“数据少”应拆成两件事。** 59万笔交易足以研究当前排序退化，31个测试日仍限制小效应与长期稳定性判断；增加bootstrap不能替代新日期。

## 尚不能解决的限制

真实新时期、标签到达时间、上游匿名字段定义、审核成本和调查结果仍然缺失。新版没有靠增加模型消除这些限制，也没有把测试集重新称作盲测。

后续提交材料若沿用原提案中的展示要求，仍需整理不超过10页的演示与8分钟录制；具体以课程实际要求为准。本轮已交付Markdown正式报告与实验材料，不把录制计为已完成。
