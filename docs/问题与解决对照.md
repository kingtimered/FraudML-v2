| 简单基线优势缺少深度 | 研究重点转向LR修复、历史增量和时期变化 | 方案已修改；不预设新方法必胜 |
| LR失败只解释为饱和 | 同存margin/概率；固定截尾与正则化对照；记录收敛 | 已完成；另作极端贡献和日期集中度诊断，不能据此确定唯一原因 |
| 历史缺失实体共享组 | H1保留旧法，H2只改缺失处理 | 已完成单因素消融；代理编码仍不是已验证身份 |
| 历史特征范围过大 | H3只加24小时次数与间隔，共4列 | 方案已收缩；不能据此代表所有历史特征 |
| 主指标差异缺少区间 | 主要配对Δ命中/精确率/召回/AP，固定3日块 | 每期1000次已完成；区间仅条件于观察模型和日期 |
| identity覆盖差异 | 本版暂缓建模，保留描述与三组设计为后续方向 | 数据审计记录覆盖；不混入核心提高复杂性 |
| 类别编码随批次变化 | 独立新版中先修逐值规范化；所有新版候选共用输入契约 | 已接入训练评分，单笔/混合批次/保存加载检查通过 |
| 匿名特征时点和意义未知 | 限定可解释范围；审计自己的派生信息边界 | 无法仅靠本数据解决上游特征可用性 |

| 无成本或真实调查结果 | 不报告避免损失、人效和部署收益 | 无法通过排序实验替代真实运营评价 |
| 旧文档与新版初稿互相冲突 | 本目录文档统一为plan2；原目录保留为归档 | 冻结方案和执行状态分开说明，真实结果已生成并核验 |

## 无法通过方案消除的限制

没有新的独立历史时期、真实标签到达时间、审核成本与结果、完整匿名特征含义。因此本项目可支持“在给定观察期和假设预算下的排序比较”，不能支持长期最优资源分配、财务收益、因果解释或生产可用性结论。

若改进未显著优于基础模型，仍可通过清晰的对照、负向结果、差异区间和复现证据完成一份深入的课程作业。
